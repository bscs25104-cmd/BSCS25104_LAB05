#Sports-Store-with-Chatbot


### Sports Items Webpage

A beginner-level responsive webpage developed to display sports products and their details.

**Technologies Used:** HTML5, CSS3

**Features:**

* Displays multiple cricket-related products with images and descriptions
* Navigation between different webpages using internal links
* Product availability information
* Contact section with LinkedIn profile integration
* Simple and clean webpage layout



### JavaScript Chatbot

A basic chatbot developed using JavaScript for simple automated user interaction.

**Technologies Used:** JavaScript

**Features:**

* Accepts user text input
* Matches user questions with predefined responses
* Provides automatic replies for basic queries
* Simulates a simple customer support interaction system
